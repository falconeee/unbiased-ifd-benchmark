# output/

Experiment outputs extracted from the notebooks into JSON.

Generated by `scripts/extract_experiment_outputs.py` (re-runnable: `python3 scripts/extract_experiment_outputs.py`).

## Layout

```
output/
├── index.json                  # global index of all 108 experiments
├── single_round/<DATASET>/     # from single_round_experiments/SignalAI_Framework_<DATASET>.ipynb
│   ├── _index.json             # notebook index + fold design
│   └── <experiment_name>.json
└── multi_round/<DATASET>/      # from multi_round_experiments/SignalAI_Framework_<DATASET>.ipynb
```

Datasets: `CWRU12k`, `CWRU48k`, `IMS`, `MFPT`, `PU`, `UOC` — 9 experiments per notebook
(MLP1D, AE1D, SAE1D, DAE1D, CNN1D, LeNet1D, ResNet18, AlexNet1D, BiLSTM).

## Schema of each experiment file

| Field | Description |
|---|---|
| `experiment_name` | name passed to `DeepLearningExperiment(name=...)`; in multiround loops the `_round_{i}` suffix is stripped |
| `experiment_name_template` | original name with the round placeholder (multiround only) |
| `dataset`, `suite` | dataset and source folder (`single_round` / `multi_round`) |
| `protocol` | protocol **detected from the output**: `single_round` or `multi_round` |
| `model` | model class instantiated in the cell |
| `description`, `section` | experiment description and markdown section title |
| `status` | `executed` or `not_executed` (cell with no output stored in the notebook) |
| `source` | notebook plus the indices of the run cell and the `show_results()` cell |
| `configuration` | `batch_size`, `lr`, `num_epochs`, `pretrain_epochs`, `recon_loss_weight`, `output_dir`, `input_length`, `num_classes`, … |
| `results` | see below |
| `fold_design` | round × fold composition printed by the fold generator (multiround only) |
| `notes` | present when `protocol` differs from `suite` |

### `results` — single round run

- `summary`: `mean_accuracy`, `std_accuracy`, `mean_f1_score`, `std_f1_score`, `num_folds` (from the `show_results()` block)
- `per_fold_metrics`: per fold — `accuracy`, `f1_score`, `precision`, `recall` (from the "DETALHES POR FOLD" table)
- `confusion_matrix`: `overall_accuracy`, `total_samples`, `figure_in_notebook`
- `folds_training_log`: per fold — `training_stage`, `accuracy`, `f1_score` and `training_history`
  with `supervised` (`epoch`, `train_loss`, `val_loss`, `time_seconds`) and `pretrain` (`epoch`, `recon_loss`)

### `results` — multiround run

- `total_rounds_planned`
- `summary`: `rounds_executed`, `mean_accuracy`, `std_accuracy`, `mean_f1_score`, `std_f1_score` (from the final consolidated report)
- `rounds[]`: per round — `mean_accuracy`, `reported_accuracy`, `fold_accuracy_mean`, `fold_f1_mean` and `folds[]`
  in the same format as `folds_training_log`

Multiround notebooks do not call `show_results()`, so they have no `per_fold_metrics` and no `confusion_matrix`.

## Notes on the source data

- `single_round_experiments/SignalAI_Framework_PU.ipynb`: no cell has stored output — all 9 files carry `status: not_executed`.
- `multi_round_experiments/SignalAI_Framework_PU.ipynb`: MLP1D, AE1D, SAE1D and DAE1D have no stored output; the other 5 ran.
- `multi_round_experiments/` IMS and UOC: the cells use `folds_singleround_deep` and the output has no rounds — these are single round runs stored in the multiround folder. Flagged in `notes` and in `protocol`.
- Duplicate experiment names across notebooks come from the notebooks themselves (e.g. `alexnet_12k` also appears in the CWRU48k notebook).
